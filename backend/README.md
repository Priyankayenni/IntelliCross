# IntelliCross — Emergency Vehicle Detection Pipeline

End-to-end pipeline for detecting emergency vehicles (ambulance, fire truck, police, disaster response) from web-collected data, training a YOLOv8 model, and serving real-time inference through a FastAPI backend with a React frontend.

## Architecture

```
project/
├── src/                        # React frontend (Vite + Tailwind + Leaflet)
│   ├── App.tsx                 # Main dashboard
│   ├── data.ts                 # Mock operational data (hospitals, signals, vehicles)
│   ├── detection.ts            # Mock detection engine (simulates YOLOv8 output)
│   └── components/
│       ├── EmergencyHeader.tsx
│       ├── VehicleCard.tsx
│       ├── RealTimeMap.tsx
│       ├── HospitalCard.tsx
│       ├── TrafficSignalPanel.tsx
│       └── DetectionPanel.tsx  # Image upload + annotation overlay + results
│
├── backend/                    # Python backend
│   ├── main.py                 # FastAPI inference service
│   ├── requirements.txt
│   ├── pytest.ini
│   ├── scripts/
│   │   ├── collect_web_data.py     # Data collector (Wikimedia Commons)
│   │   ├── extract_frames.py       # Frame extraction + YOLO auto-labeling
│   │   └── train_model.py          # YOLOv8 training script
│   └── tests/
│       ├── test_collector.py        # Unit tests (mocked HTTP)
│       ├── test_extractor.py        # Unit tests (frame extraction)
│       └── test_integration.py      # Integration tests (API endpoints)

    ├── raw/{class_name}/       # Downloaded images + metadata
    └── datasets/intellicross_web/
        ├── images/{train,val,test}
        ├── labels/{train,val,test}

```

### Frontend

```bash
npm install
npm run dev          # Start dev server (http://localhost:5173)
npm run build        # Production build
npm run typecheck    # Type check
```

### Backend

```bash
cd backend
python -m venv venv

pip install -r requirements.txt

uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

Open http://localhost:8000/docs for interactive API documentation.

## Pipeline Stages

### 1. Data Collection

Downloads openly licensed images from Wikimedia Commons API. Respects robots.txt, logs license info per file, and deduplicates via SHA-256 hashing.

```bash
cd backend
python scripts/collect_web_data.py --classes ambulance fire_truck police --per-class 30
# Or download all classes:
python scripts/collect_web_data.py --all --per-class 50
```

Output:
- `data/raw/{class_name}/` — downloaded images
- `data/raw/metadata.jsonl` — per-file metadata (source_url, license, date_collected)
- `data/raw/hashes.json` — hash index for deduplication

Classes: `ambulance`, `fire_truck`, `police`, `disaster_response_vehicle`, `car`, `bus`, `truck`, `motorcycle`, `auto_rickshaw`

### 2. Frame Extraction & Dataset Build

Extracts frames from downloaded videos, auto-labels all images using a pretrained YOLOv8 model, and organizes into YOLOv8 format.

```bash
cd backend
python scripts/extract_frames.py
# With custom splits:
python scripts/extract_frames.py --fps 2 --val-split 0.15 --test-split 0.10
# Show manual review instructions:
python scripts/extract_frames.py --review
```

Output:
- `data/datasets/intellicross_web/images/{train,val,test}/`
- `data/datasets/intellicross_web/labels/{train,val,test}/`
- `data/datasets/intellicross_web/data.yaml`

If `ultralytics` is not installed, generates stub labels so the pipeline still produces a valid dataset structure.

**Manual review:** Use LabelImg or CVAT to correct emergency-vehicle labels:
```bash
pip install labelImg
labelImg data/datasets/intellicross_web/images/train/
```

### 3. Model Training

Trains a YOLOv8 detector on the assembled dataset.

```bash
cd backend
python scripts/train_model.py
# With custom parameters:
python scripts/train_model.py --epochs 50 --batch 16 --imgsz 640 --weights yolov8m.pt
```

Output:
- `runs/emergency_detection/web_trained_v1/` — training runs
- `models/emergency_vehicle_web_v1.pt` — exported best checkpoint
- `models/training_report.json` — training metrics (mAP50, mAP50-95)

If `ultralytics` is not installed or no dataset exists, stubs successfully and writes a placeholder model file.

### 4. Real-Time Inference

FastAPI service with two detection endpoints.

```bash
cd backend
uvicorn main:app --reload
```

**Endpoints:**

| Method | Path | Description |
|--------|------|-------------|
| GET | `/health` | Health check + model status |
| POST | `/api/detect-image` | Upload image → detections (class, confidence, bbox) |
| POST | `/api/detect-stream` | Upload video → per-frame detections |
| GET | `/docs` | Interactive API docs (Swagger UI) |

**Response schema (`/api/detect-image`):**
```json
{
  "detections": [
    {
      "class_name": "ambulance",
      "class_id": 0,
      "confidence": 0.94,
      "bbox": {"x1": 100, "y1": 50, "x2": 250, "y2": 180},
      "is_emergency": true
    }
  ],
  "top_class": "ambulance",
  "top_confidence": 0.94,
  "emergency_detected": true,
  "model_source": "web_trained_v1",
  "processing_time_ms": 42,
  "image_width": 640,
  "image_height": 480
}
```

The service uses the trained model (`models/emergency_vehicle_web_v1.pt`) if available, falls back to pretrained YOLOv8n (`base_model`), or returns mock detections if `ultralytics` is not installed.

### 5. Frontend Integration

The React frontend has a "Test Detection" panel accessible via the "New detection" button:

1. Upload an image (drag-and-drop or click to browse)
2. Click "Run detection" — shows an analyzing animation with scan effect
3. Results display with bounding boxes drawn over the image, color-coded by class
4. Detection list shows each object with confidence bar
5. Emergency vehicles are flagged with an alert banner

When the backend is running, the frontend can call `/api/detect-image` directly. In demo mode (no backend), the frontend uses the built-in mock detection engine that produces realistic YOLOv8-style output.

### 6. Testing

```bash
cd backend
pip install pytest httpx
pytest -v
```

Tests cover:
- **Unit (collector):** hash computation, robots.txt check, Wikimedia API parsing (mocked HTTP)
- **Unit (extractor):** class mappings, dataset splitting, data.yaml generation, stub labeling
- **Integration (API):** `/health`, `/api/detect-image` schema validation, error handling

## Connecting Frontend to Backend

To connect the React frontend to the live inference API instead of mock detections:

1. Start the backend: `cd backend && uvicorn main:app --reload`
2. In `src/components/DetectionPanel.tsx`, replace the `runMockDetection()` call with a `fetch()` to `http://localhost:8000/api/detect-image`
3. Send the uploaded file as `multipart/form-data`
4. Map the response `bbox` from `{x1, y1, x2, y2}` pixel coordinates to the `{x, y, width, height}` percentage format used by the overlay
